# Offline-First Smart Companion

A small Jetpack Compose Android app that keeps submitted data on the device while offline and marks queued items as synced when a validated network becomes available.

## Build

Open this repository in Android Studio (Ladybug or newer) and run the `app` configuration. The project uses the Gradle wrapper supplied by Android Studio if one is generated locally.

The original snippet was stored only in `README.md`, so this repository now contains a runnable Android project under `app/`.
